## Load from multiple texture packs at the same time

Luanti now supports loading from multiple texture packs at the same time.
The order of the texture packs can be rearrangend in the refined 'Content' tab in the main menu.
This changes prioritization of textures, so that textures from the first texture pack in the list will be used first, and if a texture is not found there, it will be searched for in the next texture pack in the list, and so on. 

https://github.com/luanti-org/luanti/pull/17552

## Translating to English is now possible 

Starting with this release, developers can now translate their games and mods from their native language to English.
By default, Luanti will still assume that the game or mod is in English, but developers can now set the source language in their translation files.
To learn more, check out the [Lua API documentation](https://api.luanti.org/translations/#monolingual-translations-non-english-source-locale).

https://github.com/luanti-org/luanti/pull/17454

## Lua API to customize the world lighting

It is now possible to customize the world lighting in Luanti using the Lua API. 
https://github.com/luanti-org/luanti/pull/16697

## Formspec: new "listimages" element, new editable style

There is a new "listimages" formspec element, which allows to style inventory slots with textures.
This gives modders and game developers more freedom to customize the look of their inventory slots and make it fit their style better.

https://github.com/luanti-org/luanti/pull/17305
 
## Main Menu: Warning messages for potentially dangerous settings

The setting is still available on desktop, but a warning message will be shown when enabling it.
Additionally, it is now impossible on Android to disable the Lua sandbox, which is a security risk.
https://github.com/luanti-org/luanti/pull/17578

## Re-added the client setting to disable digging particles
This setting was removed in 5.11.0 and has now been re-added to give players more control over their client and visual experience.
It can be found in the "Effects" section of the settings menu.

https://github.com/luanti-org/luanti/pull/17406

## Bug Fixes, Performance Improvements, and Other Changes 

As always, this release contains many bug fixes, performance improvements, and other changes.
